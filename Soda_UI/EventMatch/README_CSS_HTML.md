# EventMatch — интерфейс команды Soda

Исходный HTML/CSS/JavaScript-дизайн подключён к серверу Go и каталогу организаторов. Сохранены оливковая палитра, навигация, карточки и адаптивные страницы. Тексты интерфейса — на русском.

Запуск из корня репозитория:

```bash
go run .
```

Открыть http://127.0.0.1:8080. Сборка интерфейса и npm не нужны. Прямое открытие `dist/index.html` или запуск только статического сервера не подключает API.

Сценарий: свободное описание или ручная форма → редактируемые параметры и пожелания → подтверждение → до трёх карточек. Есть полный профиль, отсутствие категории, отсутствие совпадений, загрузка, ошибка сервиса и сообщения о недоступности AI. Все 17 категорий приходят с сервера.

Демонстрационные 12 профилей заменены 66 исходными профилями. Поиск и проверка условий выполняются сервером; браузер не содержит API-ключей и отдельного алгоритма фильтрации.

Файлы: `dist/index.html` — оболочка, `dist/styles.css` — стили, `dist/app.js` — формы, состояние и запросы к API. Подробнее об AI, данных, запуске и проверках — в [основном README](../../README.md).
